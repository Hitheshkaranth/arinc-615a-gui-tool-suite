# ARINC 615A Data Loader Application {#arinc_615a_data_loader_gui_main}

Qt Based Application, which provides Wizards for ARINC 615A Operations:
 - Information Operation,
 - Upload Operation,
 - Media Defined Download Operation, and
 - Operator Defined Download Operation.

It also provides ARINC 665 Media Set Management:
 - Importing of Media Sets
 - Media Set Generation
